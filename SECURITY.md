# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in GridPulse Intelligence, please do not open a public issue containing sensitive details.

Please report the vulnerability privately through GitHub's vulnerability reporting features when available.

Include:

- A description of the vulnerability
- Steps to reproduce it
- The affected component or endpoint
- Potential impact
- Any suggested remediation

Please do not include credentials, API keys, tokens, or other sensitive information in public issues.

## Scope

Security reports related to the following areas are especially useful:

- GridPulse API
- Web application security
- Dependency vulnerabilities
- GitHub Actions and CI/CD
- Secrets exposure
- Infrastructure configuration

GridPulse Intelligence is currently a portfolio and engineering project and should not be treated as a production utility-grid operational system.
